# Contributing to Aletheia

Thank you for your interest in contributing to Aletheia.

Aletheia is an experimental research project exploring artificial scientific reasoning, verification, hypothesis generation, and reproducible research.

Contributions are welcome, especially when they improve the project's scientific rigor, reproducibility, reliability, or usability.

---

## Before Contributing

Please read the project documentation before making changes:

- `README.md` — Project overview
- `ARCHITECTURE.md` — System architecture
- `RESEARCH.md` — Research direction
- `ROADMAP.md` — Planned development

---

## Types of Contributions

Useful contributions include:

- Bug fixes
- Tests
- Documentation
- Scientific experiments
- Verification methods
- Mathematical models
- Reasoning improvements
- Reproducibility improvements
- Performance improvements
- New research ideas
- Examples and demonstrations

---

## Scientific Contributions

Scientific contributions should clearly distinguish between:

- Established facts
- Derived results
- Hypotheses
- Experimental observations
- Speculation

When proposing a scientific claim, provide supporting evidence whenever possible.

Reproducible experiments are strongly encouraged.

---

## Pull Requests

Before submitting a pull request:

1. Make sure your changes are focused and understandable.
2. Update documentation when necessary.
3. Add or update tests when appropriate.
4. Explain the purpose of the change.
5. Clearly identify any assumptions or limitations.

Pull requests should describe:

```text
What changed?
Why was it changed?
How was it tested?
What limitations remain?

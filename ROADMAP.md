# Roadmap

## 0.1 — Cognitive foundation

Focus: architecture, controlled loop and minimal reasoning.

Planned deliverables:

- repository scaffolding;
- cognitive core abstraction;
- task state model;
- working memory module;
- minimal orchestration loop;
- verification layer;
- tests and documentation.

## 0.2 — Persistent memory

Status: implemented as a minimal, auditable foundation.

Delivered:

- persistent memory backend using SQLite;
- episodic memory store for completed tasks;
- semantic memory support with epistemic status tracking;
- memory indexing and retrieval for prior-task context;
- task history tracking and provenance metadata.

Planned follow-ons:

- richer retrieval policies;
- better contradiction-resolution workflows;
- more explicit procedural memory consolidation.

## 0.3 — Reasoning and tools

Status: implemented as a minimal, traceable reasoning layer.

Delivered:

- explicit formal derivation traces;
- symbolic mathematics through SymPy;
- equation solving and symbolic differentiation;
- basic verification and counterexample checks.

Planned follow-ons:

- stronger assumption handling;
- richer rule applications;
- more robust formal verification.

## 0.4 — Scientific knowledge system

Status: implemented as a structured scientific knowledge layer.

Delivered:

- scientific knowledge types and epistemic status separation;
- domain tagging and scientific subdomains;
- equation, model, definition, law, and hypothesis representations;
- assumptions, constraints and validity-condition tracking;
- persistence and retrieval for structured scientific knowledge;
- relation records and provenance support.

Planned follow-ons:

- richer model comparison;
- more explicit measurement and experiment objects;
- deeper contradiction resolution and inference policies.

## 0.5 — Hypothesis engine

Focus on generating, sequencing and testing candidate hypotheses.

Planned deliverables:

- hypothesis schema;
- prediction generation;
- contradiction and falsification checks;
- evidence comparison.

Status: implemented as a minimal, explicit hypothesis engine.

## 0.6 — Simulation and experiment

Add experiment design and simulated validation.

Planned deliverables:

- experiment schemas;
- simulation wrappers;
- expected/observed comparison;
- result summarization;
- reproducibility metadata;
- execution backend abstraction.

Status: implemented as a minimal computational experimentation layer.

## 0.7 — Self-criticism and verification

Add metacognitive checks.

Planned deliverables:

- contradiction detection;
- confirmation-bias checks;
- hidden-assumption detection;
- mathematical validation workflows;
- verification result records with provenance and limitation logging;
- explicit self-critique of generated conclusions.

Status: implemented as a minimal verification and self-criticism layer.

## 0.8 — Scientific discovery loop

Create a repeatable research cycle.

Planned deliverables:

- task-to-model-to-hypothesis pipeline;
- falsification loop;
- model update mechanism;
- research-history persistence.

## 0.9 — Autonomous planning

Introduce constrained autonomy for selecting the next research action.

Planned deliverables:

- uncertainty-driven decision selection;
- information-value estimation;
- bounded autonomy controls.

## 1.0 — Integrated prototype

Consolidate the system into a single integrated scientific intelligence prototype.

Planned deliverables:

- end-to-end research loop;
- domain reasoning prototypes;
- benchmark suite;
- internal evaluation of uncertainty and reliability.

## Execution note

These roadmap phases are development milestones, not claims about actual intelligence or scientific correctness.
